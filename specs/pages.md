# 零压画铺 · 页面规范 (Pages)

> 所属：零压画铺 Chill Sketch Hub　｜　依赖：[design-tokens.md](./design-tokens.md) · [components.md](./components.md)
> 说明：底部导航为 3 个 Tab，顺序为 文摘 → 我的手账 → 耐丑训练；「新手绘画指南」不再占用 Tab，改由「我的手账」搜索行右侧的小图标进入（子页面形式）。
> 通用布局：每页均为「固定头 + 单一滚动区」——页面头部控件（标题 / 搜索行 / 新增入口 / 返回栏 / 模式切换 / 营业牌等）固定不动，仅下方内容容器滚动。

## 1. 全局骨架（App Shell）

```text
┌───────────────────────────────┐
│  顶部安全区 --safe-t            │
├───────────────────────────────┤
│  Header（固定，不随滚动）        │  标题 / 搜索行 / 新增入口 / 返回栏等
├───────────────────────────────┤
│                               │
│      内容滚动区（唯一滚动容器）   │
│                               │
│                        (FAB)  │  按页出现
├───────────────────────────────┤
│    文摘 │ 我的手账 │ 耐丑训练    │  固定底部导航（3 Tab）
│   ──────  --safe-b             │
└───────────────────────────────┘
```

- 左右边距 `--sp-4`；区块间距 `--sp-6`。
- 滚动容器底部预留 `--nav-h + --safe-b + --sp-6`。
- 导航与页面一一对应：文摘 → `ExcerptsView`，手账 → `JournalView`，训练 → `TrainingView`；**指南 `GuideView` 为手账的子页面**，随底部导航仍高亮「我的手账」。
- **各 Tab 页均不展示页面招牌 / 标题条**（原「木牌招牌」已移除）。

## 2. 页面一：绘画指南 GuideView —「店主的心法墙」（手账子页）

**定位**：静态心态建设页，随时提供心理安抚。**以子页面形式从「我的手账」进入**，顶部带返回箭头。

### 2.1 布局

```text
[子页顶栏]  ‹ 返回        新手绘画指南        (占位)   ← 固定，不随滚动
─────────────────────────────
[开场] 一段温柔引言（便签卡）
─────────────────────────────
[区块] 破除迷思  ← 小节吊牌标题
   └ 便签卡：成年人画画不是为了考美院…
─────────────────────────────
[区块] 五步降维路径  ← 小节吊牌标题
   └ 竖向时间轴（5 个便签，见 2.2）
─────────────────────────────
```

- 顶栏「返回箭头」见 components §3.3；点击返回「我的手账」。进入指南时底部导航仍高亮「我的手账」。
- 顶部无招牌，正文即为内容首屏。

### 2.2 五步路径（时间轴）

- 竖向时间轴：左侧一条虚线"线装"纹理 + 5 个圆形节点；右侧为便签卡。
- 每步卡片：序号 + 步骤名（`--fs-h2`）+ 一句说明（`--fs-body`）。
- 节点颜色可在 `--color-sage → --color-wood → --color-orange` 间渐变，体现"由浅入深"。

| 步骤 | 标题 | 说明 |
| --- | --- | --- |
| 1 | 涂鸦 | 解除"不会画"的心理，建立手感 |
| 2 | 形状观察 | 把世界简化成圆、方、三角 |
| 3 | 线描 / 简笔 | 画生活小物，成就感高 |
| 4 | 构图与表达 | 画面布局与留白 |
| 5 | 素描 | 带观察力再进入，不再痛苦 |

### 2.3 状态与交互

- 纯静态滚动页，无数据依赖，**离线可读**。
- 卡片入场：进入视口时轻微上浮淡入（`translateY 12px→0`，`--ease-out`），`IntersectionObserver` 触发一次即可。
- 底部 FAB「求打气」：点击弹出随机语录气泡（见 components §10）。

## 3. 页面二：文摘 ExcerptsView —「柜台的摘抄本」

**定位**：记录好词好句、令人放松愉悦或振奋的句子、任何自己想记录的句子；既是情绪收藏罐，也是「一句话画图」的灵感来源。

### 3.1 布局

```text
[固定头]  ＋ 写一句新摘抄        ← 折叠态
   （展开）多行内容 / 出处·作者 / 选标签 / [收藏] [保存]
[固定头]  [搜索框]  [标签筛选 ▾]  [只看收藏 ★]
─────────────────────────────
[列表·滚动]  倒序
   ┌ 句子卡 ┐
   │ “好句子……”      │
   │ —— 出处 / 作者   │
   │ #好词好句 #治愈   │
   │  ★收藏   [画这句]  [编辑] [删除] │
   └────────┘
   …
```

> 顶部不再展示「摘抄本」招牌；摘抄器与工具条位于固定头，仅下方句子列表滚动。

### 3.2 摘抄器（Input Area）

- **折叠态**：一张卡片，显示「＋ 写一句新摘抄」，点击展开为编辑卡。
- **展开态**：
  - 多行文本域（`--font-hand` 或 `--fs-body`，`min-height` 约 3 行，placeholder 铺子语气："记一句喜欢的？"）。**内容必填**，为空时 [保存] 禁用。
  - 出处 / 作者：单行输入（可选），placeholder："出自哪里？（可留白）"。
  - 标签：预设 `#好词好句 / #治愈放松 / #振奋打气 / #灵感画题 / #随手记`，可多选（Tag 组件），也可自定义。
  - [收藏 ★] 切换（可选）：勾选后该句进入收藏分组。
  - 操作：[取消]（次按钮） / [保存]（主按钮）。
- 保存后：写入 IndexedDB `excerpts`，列表顶部插入，摘抄器收起并清空。

### 3.3 列表与工具条

- 按 `createdAt` 倒序；单条使用 **Excerpt Card**（components §13）。
- 工具条：关键词搜索（匹配正文 / 出处）、标签筛选、**只看收藏**开关；筛选条件可组合。
- 长句省略号截断，点击卡片展开全文。

### 3.4 「画这句」（一键作画）

- 句子卡点击 [画这句]：跳转到训练页，**自动切到「一句话画图」模式并预填该句**（见 §5.3）。
- 该句在训练页作为灵感提示常驻，画完打卡后，产生的记录可在手账对应模式标签下看到。

### 3.5 状态与交互

| 状态 | 表现 |
| --- | --- |
| 空 | 空状态插画 + "还没有摘抄，收一句喜欢的吧 🍃" |
| 有数据 | 句子卡列表 |
| 筛选无结果 | "没找到，换个词试试" |
| 保存中 | 保存按钮 loading，禁用重复提交 |

- 文摘为离线可用；删除需二次确认。

## 4. 页面三：我的手账 JournalView —「作品展示墙」

**定位**：打卡记录 + 情绪碎碎念 + 小红书分享转化。

### 4.1 布局

```text
[固定头]  [🔍 搜索框……] [💡]        ← 搜索行；右侧💡为「新手绘画指南」入口
[固定头]  ＋ 贴一张新作品            ← 折叠态
   （展开）多行文本 / 上传图片 / 选标签 / [发布]
─────────────────────────────
[时间轴·滚动]  倒序列表
   ┌ 2026-10-14 周三 ┐   ← 手写体日期
   │ [图片]          │
   │ 文本碎碎念…      │
   │ #日常涂鸦 #耐丑训练│
   │      [生成分享图] │
   └─────────────────┘
   …
─────────────────────────────
                        (求打气 FAB)
```

- 顶部无「作品展示墙」招牌。
- **搜索行**（固定头，见 §4.2）：左侧圆角搜索框 + 右侧「新手绘画指南」小图标按钮（💡）；点击图标以子页面打开指南（§2）。
- 发布器位于固定头，仅下方时间轴滚动。

### 4.2 搜索（按标签 / 文字）

- 搜索框 placeholder 铺子语气，支持按**标签**或**正文文字**实时过滤（如 `杯子` / `#日常涂鸦`）。
- 过滤逻辑：命中记录即时显示，未命中隐藏；**日期分组标题**随组内是否仍有可见记录联动显隐；输入非空时显示清空（✕）按钮。
- 无任何命中 → 显示空状态「没找到相关作品，换个词试试～」。
- 搜索行右侧的 💡 小图标为「新手绘画指南」入口，与搜索输入同一行（详见 components §3.4）。

### 4.3 发布器（Input Area）

- **折叠态**：一张卡片，显示「＋ 贴一张新作品」，点击展开为编辑卡。
- **展开态**：
  - 多行文本域（`--fs-body`，`min-height` 约 4 行，placeholder 铺子语气："今天画了点什么？"）。
  - 图片上传：调用 `accept="image/*"`（相册 / 相机）；选中后**前端压缩预览**（Web Worker + `createImageBitmap`/`OffscreenCanvas`，限制最长边、纠 EXIF 方向），预览显示压缩后缩略图。
  - 标签选择：预设 `#日常涂鸦 / #耐丑训练 / #一句话画图 / #情绪宣泄`，可多选（Tag 组件）。
  - 操作：[取消]（次按钮） / [发布]（主按钮，无内容时禁用）。
- 发布后：写入 IndexedDB（存 Blob），列表顶部插入新记录，发布器收起并清空。

### 4.4 时间轴列表

- 按 `createdAt` 倒序；按日期分组，组头为手写体日期（`--font-hand`）。
- 单条记录卡（见 components §6 记录卡）：图片（懒加载）→ 文本 → 标签 → 底部操作条。
- 训练归档的记录会带模式标签（看图 → `#耐丑训练`，一句话 → `#一句话画图`）。
- 底部操作条：`[生成分享图]`（文字按钮）+ `[删除]`（文字按钮，二次确认）。

### 4.5 分享图弹层（Share to XHS）

- 点击【生成分享图】→ 用 **Canvas 2D 直绘 3:4 海报**（背景纸纹 + 图片 + 文本 + 日期 + 印章/贴纸装饰），不依赖 html2canvas。
- 弹层：遮罩 + 居中 3:4 卡片（圆角 `--radius-xl`）+ 底部操作条：
  - [保存图片]（主按钮，触发下载 / 长按保存引导）
  - [关闭]（次按钮）
- 生成中显示骨架 / loading，避免白屏。

### 4.6 状态与交互

| 状态 | 表现 |
| --- | --- |
| 空 | 空状态插画 + "还没有作品，去贴第一张贴纸吧" |
| 有数据 | 时间轴列表 |
| 发布中 | 发布按钮 loading，禁用重复提交 |
| 存储失败 | 提示"存不下了，试试导出备份"，引导导出 |

- 空状态与列表均为离线可用；数据写入失败（配额）时给出明确提示。

## 5. 页面四：耐丑训练 TrainingView

**定位**：用限时/不限时的"随手画"强制打破完美主义；不评判丑美，画完就赢。

### 5.1 布局

```text
[固定头]  [模式切换]  看图速写 ｜ 一句话画图    ← Segmented（components §14）
[固定头]  [营业牌] 今日营业 2 张   ● ● ○ ○ ○
─────────────────────────────
模式 A（看图速写）· 待命态（idle）：
[选图区]  内置参考图 ｜ 自选 / 上传一张     [换一张]
[参考图卡]  已选参考图（确认后锁定为画题）
[开始挑战]（强调按钮）  ← 选好图后才开始计时；待命态不出现倒计时与鼓励语
   状态 running：顶部大号倒计时（09:42）+ 下方大面积画题图，供用户照着画
   状态 finished：全屏结果层（印章 + 撒花）→ [立即拍照打卡]
─────────────────────────────
模式 B（一句话画图）：
[句子卡]  灵感句子 + [换一句]（来源：文摘 / 内置句库）
[规则条] 想到哪画到哪 · 不限时 · 画完就赢
   状态 idle：   [开始画]（强调按钮）
   状态 drawing：句子卡常驻，不限时，[画完了 · 打卡]
   状态 finished：全屏结果层（印章动效）→ [立即拍照打卡]
─────────────────────────────
```

- 顶部无「速写挑战台」招牌；**固定头**仅含模式切换 + 营业牌，其下内容区滚动。

### 5.2 模式 A：看图速写（限时）

- **参考图来源（两种）**：
  - **内置**：从**内置本地资源**随机取一张（生活小物 / 手作 / 植物），进入页面先随机展示，右上角【换一张】再随机。
  - **自选 / 上传**：支持用户从相册 / 相机选一张自己的图作为画题；上传后前端压缩预览（与手账发布器同源能力）。
- **参考图卡**：大图 + 图钉 / 胶带装饰（components §6）；选定后**锁定为本题画题**。
- **待命态（idle）**：只呈现选图区 + 参考图卡 + [开始挑战]，**不出现倒计时**，也**不展示「画丑无罪 · 画完就赢」类鼓励语**（避免刻意）。
- **计时态（running）视觉**：**顶部一块鲜明的倒计时条**（暖橘渐变底 + 白色发光进度条 + 大号白色 `mm:ss`），其下方为**大面积画题图**供用户照着画。
- **计时器**：
  - 固定 **10:00** 倒计时，**选好图之后才开始**——在 idle 阶段可自由换图 / 上传，点 [开始挑战]（= 确认当前画题）后才启动计时。
  - **实现要点**：基于「截止时间戳 − 当前时间」计算剩余，不依赖 `setInterval` 累加（后台节流 / 锁屏会暂停）。
  - 计时期间申请 **Screen Wake Lock** 防熄屏；离开页面 / 结束时释放。

### 5.3 模式 B：一句话画图（不限时）

- **灵感来源**：优先取「文摘」（§3）中的句子；若从文摘 [画这句] 进入则**预填该句**。也可从内置句库 `data/quotes.js` 随机取句；提供【换一句】。
- **不限时**：无倒计时、无进度环，不申请 Wake Lock；允许慢慢画、慢慢改。
- **句子卡**：以句子卡（components §13 复用）常驻显示灵感句，可长按展开全文。
- **规则条**：温和鼓励语（如"想到哪画到哪 · 画完就赢"）。
- 完成后同样进入结果层与打卡闭环。

### 5.4 状态机

```text
模式 A（限时）
idle ──[开始挑战]──▶ running ──[倒计时归零]──▶ finished ──[立即拍照打卡]──▶ 归档并 +1
  ▲                                                                        │
  └────────────────────────[重置为下一轮]◀─────────────────────────────────┘

模式 B（不限时）
idle ──[开始画]──▶ drawing ──[画完了·打卡]──▶ finished ──[立即拍照打卡]──▶ 归档并 +1
  ▲                                                                        │
  └────────────────────────[重置为下一轮]◀─────────────────────────────────┘
```

| 模式 | 状态 | 内容 | 主操作 |
| --- | --- | --- | --- |
| A | idle | 选图区（内置随机 / 自选上传）+ 参考图卡（无倒计时、无鼓励语） | [开始挑战]（= 确认画题并开始计时） |
| A | running | 顶部鲜明倒计时条 + 下方大面积画题图，其余弱化；屏蔽误触 | （可选 [放弃]） |
| A | finished | 全屏结果层：印章动效 + 文案 + 按钮 | [立即拍照打卡] |
| B | idle | 句子卡、[换一句]、规则条 | [开始画]（强调按钮） |
| B | drawing | 句子卡常驻，无计时 | [画完了 · 打卡] |
| B | finished | 全屏结果层：印章动效 + 文案 + 按钮 | [立即拍照打卡] |

- 切换模式（components §14）会重置当前会话状态回到 idle。
- 模式 A 的 idle 阶段可自由换图 / 上传，确认选好图后 [开始挑战] 才启动 10:00 倒计时。
- 结束后反馈：印章动效（components §4）；`vibrate` 仅 Android，iOS 用视觉 +（可选）音效兜底。

### 5.5 打卡闭环

- [立即拍照打卡] → 调用相机拍照 → 前端压缩 → 自动按模式打标签归档到「我的手账」→ 营业牌进度 +1。
  - 模式 A → `#耐丑训练`
  - 模式 B → `#一句话画图`
- 打卡成功可在手账页看到新记录；训练页回到 idle 供下一轮。

### 5.6 每日进度与肯定（不设上限）

- 营业牌（components §8）：显示"今日营业 n 张"，进度按**日期 Key** 存储，跨天自动重置；两种模式**共用同一进度计数**。
- **第 5 次起（强烈肯定）**：当日累计达 **5 次及以上**时，**每一次提交**都弹出金章 + **撒花动画**，文案如"五连开张 · 状态拉满"。
- **不封顶、不结束**：超过 5 次后每次完成继续触发金章 + 撒花，营业牌叠加星标计数，文案递增赞扬（如"超常营业 · 今日 7 张""今日卷王"），由 `data/quotes.js` 提供。

## 6. 页面间关系

```text
我的手账 ──(💡 小图标)──▶ 绘画指南（子页面，返回箭头回手账）
绘画指南 ──(随时安抚)──▶ 求打气
文摘 ──(【画这句】预填句子)──▶ 耐丑训练 · 一句话画图
耐丑训练 ──(打卡自动归档 #耐丑训练 / #一句话画图)──▶ 我的手账
文摘 ──(作为灵感句库)──▶ 耐丑训练 · 一句话画图
我的手账 ──(Canvas 3:4 海报)──▶ 小红书分享
```

- 训练页（两种模式）产生的记录统一进入手账时间轴，保证"打卡闭环"完整。
- 文摘既独立成页，又作为「一句话画图」的句子来源。
- 绘画指南自「我的手账」搜索行的小图标进入，为子页面，返回后回到手账。
- 求打气语录在指南页与手账页均可触达。
