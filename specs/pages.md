# 松鸦画坊 · Chill Sketch Hut 页面规范 (Pages)

> 所属：松鸦画坊 Chill Sketch Hut　｜　依赖：[design-tokens.md](./design-tokens.md) · [components.md](./components.md)
> 版本：对齐 PRD [chill_sketch_hut_v1_4.md](../chill_sketch_hut_v1_4.md)
> 说明：底部导航为 3 个 Tab，顺序为 文摘 → 作品墙 → 耐丑训练；「新手绘画指南」不占用 Tab，由「作品墙」搜索行右侧的 💡 图标进入（子页面形式）。
> 通用布局：每页均为「固定头 + 单一滚动区」——页面头部控件（标题 / 搜索行 / 新增入口 / 返回栏 / 模式切换 / 营业牌等）固定不动，仅下方内容容器滚动。

## 1. 全局骨架（App Shell）

```text
┌───────────────────────────────┐
│  顶部安全区 --safe-t            │
├───────────────────────────────┤
│  Header（固定，不随滚动）        │  搜索行 / 新增入口 / 返回栏 / 模式切换 / 营业牌等
├───────────────────────────────┤
│                               │
│      内容滚动区（唯一滚动容器）   │
│                               │
│                     (松鸦打气) │  作品墙页右下角悬浮
├───────────────────────────────┤
│    文摘 │ 作品墙 │ 耐丑训练      │  固定底部导航（3 Tab）
│   ──────  --safe-b             │
└───────────────────────────────┘
```

- 左右边距 `--sp-4`；区块间距 `--sp-6`。
- 滚动容器底部预留 `--nav-h + --safe-b + --sp-6`。
- 导航与页面一一对应：文摘 → `ExcerptsView`，作品墙 → `JournalView`，训练 → `TrainingView`；**指南 `GuideView` 为作品墙的子页面**，进入时底部导航仍高亮「作品墙」。
- **各 Tab 页均不展示页面招牌 / 标题条**（原「木牌招牌」已移除）；品牌名仅出现在指南页封面卡与海报中。

## 2. 页面一：反焦虑绘画指南 GuideView —「松鸦店长的便签墙」（作品墙子页）

**定位**：静态心态建设页，像松鸦店长的便签墙一样随时提供心理安抚。**以子页面形式从「作品墙」进入**，顶部带「返回作品墙」按钮。

### 2.1 布局

```text
[子页顶栏]  ‹ 返回作品墙     松鸦店长的便签墙 📌   ← 固定，不随滚动
─────────────────────────────
[封面卡]  CHILL SKETCH HUT MANIFESTO
         给大人的「反焦虑绘画心法」+ 引言 + 店长落款（便签卡 + 和纸胶带）
─────────────────────────────
[区块] 🚫 破除第一大迷思：为什么要先练素描？（图钉便签卡 + 「真相是」高亮条）
─────────────────────────────
[区块] 🪜 松弛五步降维路径（虚线线装竖向时间轴，5 个便签，见 2.2）
─────────────────────────────
[底部] 引导卡：店长引言 + [去「耐丑训练室」随便画两笔 →]
─────────────────────────────
```

- 顶栏「返回作品墙」按钮见 components §3.3；进入指南时底部导航仍高亮「作品墙」。
- 顶部无招牌，正文即为内容首屏；内容为杂志 / 便签墙混排，可自由滚动。
- 该页为**纯静态、离线常驻**，无数据依赖。

### 2.2 松弛五步降维路径（时间轴）

- 竖向时间轴：左侧一条虚线"线装"纹理 + 5 个圆形节点；右侧为便签卡。
- 每步卡片：`STEP 0n · 步骤名`（`--fs-h2`）+ 右侧小药丸标签 + 一句说明（`--fs-body`）。
- 节点颜色在 `--color-sage → --color-wood → --color-orange` 间变化，体现"由浅入深"。

| 步骤 | 标题 | 小标签 | 说明 |
| --- | --- | --- | --- |
| STEP 01 | 放肆涂鸦 | 破冰期 | 在废纸上画满螺旋线、波浪线、乱麻团，**解除"我不会画"的心理封印**，找回儿时涂抹的爽感 |
| STEP 02 | 形状观察 | 万物皆几何 | 把世界降维成 **◯ 圆、□ 方、△ 三角**，瞬间不再害怕下笔 |
| STEP 03 | 线描 / 生活简笔 | 高成就感 | 单线条勾勒咖啡杯、拖鞋、多肉，抖动线条也是个人风格 |
| STEP 04 | 构图与表达 | 画面呼吸感 | 学会留白，配上心情句或【文摘】中的句子，图文结合成艺术品 |
| STEP 05 | 自然进入光影素描 | 水到渠成 | 有观察习惯与放松心态后，再补一点阴影与体积，素描不再痛苦 |

### 2.3 状态与交互

- 纯静态滚动页，**离线可读**。
- 卡片入场：进入视口时轻微上浮淡入（`translateY 12px→0`，`--ease-out`），`IntersectionObserver` 触发一次即可。
- 底部引导卡 [去「耐丑训练室」随便画两笔 →]：跳转训练页（§5）。
- 此页**不含**打气按钮；「松鸦打气」仅在作品墙页提供（§4）。

## 3. 页面二：文摘 ExcerptsView —「柜台上的摘抄本 / 话签罐」

**定位**：记录好词好句、令人放松愉悦或振奋的句子、任何自己想记录的句子；既是情绪收藏罐，也是「一句话画图」的灵感来源。

### 3.1 布局

```text
[固定头]  [搜索框]                      [＋ 记一句]   ← 搜索行
[固定头]  [全部] [⭐收藏] [#好词好句] [#放松] [#振奋] [#画题]   ← 筛选胶囊
─────────────────────────────
[滚动]  （折叠）新增/编辑句子表单卡：内容 / 出处·作者 / 选标签 / [夹进摘抄本 🔖]
─────────────────────────────
[列表·滚动]  倒序
   ┌ 书签卡 ┐
   │ “好句子……”        │
   │ —— 出处 / 作者      │
   │ #好词好句 #放松      │
   │  ★收藏  [🎨 画这句] [编辑] [删除] │
   └────────┘
   …
```

> 顶部不再展示「摘抄本」招牌；搜索行与筛选条位于固定头，仅下方列表滚动。

### 3.2 新增 / 编辑句子表单卡

- **触发**：固定头 [＋ 记一句] 展开表单卡（再次点击或 [收起 ✕] 折叠）。编辑既有句子时复用同一卡，标题切为编辑态。
- **字段**：
  - 多行内容文本域（`--fs-body`，`min-height` 约 2 行，placeholder："写下让你放松、愉悦或有画面感的句子（必填）…"）。**内容必填**，为空时 [保存] 禁用。
  - 出处 / 作者：单行输入（选填），placeholder："出处 / 作者（选填，如：汪曾祺《人间草木》）"。
  - 标签：预设 `#好词好句 / #放松 / #振奋 / #画题`，可多选（Tag 组件）。
  - 操作：[夹进摘抄本 🔖]（主按钮）。
- 保存后：写入 IndexedDB `excerpts`，列表顶部插入 / 原位更新，表单收起并清空。

### 3.3 列表与工具条

- 按 `createdAt` 倒序；单条使用 **Excerpt Card**（components §13）。
- 工具条：关键词搜索（匹配正文 / 出处 / 标签）、筛选胶囊（`全部 / ⭐ 收藏 / #好词好句 / #放松 / #振奋 / #画题`）；筛选条件可组合。
- 长句省略号截断，点击卡片展开全文。

### 3.4 「🎨 画这句」（一键作画）

- 句子卡点击 [🎨 画这句]：跳转到训练页，**自动切到「一句话画图」模式并预填该句**（见 §5.3）。
- 该句在训练页作为灵感提示常驻；画完打卡后，产生的记录可在作品墙对应模式标签下看到。

### 3.5 状态与交互

| 状态 | 表现 |
| --- | --- |
| 空 | 空状态插画 + "还没有摘抄，收一句喜欢的吧 🍃" |
| 有数据 | 书签卡列表 |
| 筛选无结果 | "没找到，换个词试试" |
| 保存中 | 保存按钮 loading，禁用重复提交 |

- 文摘为离线可用；删除采用**防误删原位二次确认**（components §18）。

## 4. 页面三：作品墙 JournalView —「画作展示墙 / 集章墙」

**定位**：打卡记录 + 情绪碎碎念 + 小红书分享转化。默认主 Tab。

### 4.1 布局

```text
[固定头]  [🔍 搜索框……]  [📦]  [💡 指南]   ← 搜索行：搜索 + 备份 + 指南入口
[固定头]  #全部 #日常涂鸦 #耐丑打卡 #情绪宣泄 #生活小物   ← 快捷标签筛选条
─────────────────────────────
[滚动]  黑板欢迎横幅 + 「随手贴一张」发布器
        （多行碎碎念 / 传图必选 + ✨提亮纸面 / 选标签 / [盖章上墙 💮]）
─────────────────────────────
[时间轴·滚动]  按日期分组倒序
   ┌ 2026-10-14 周三 ┐   ← 手写体日期
   │ [图片（点击灯箱）]  │
   │ 碎碎念…            │
   │ #日常涂鸦 #耐丑打卡  │
   │   [生成分享图] [✏️编辑] [删除] │
   └─────────────────┘
   …
─────────────────────────────
                    (🐦 松鸦打气)   ← 右下角悬浮
```

- 顶部无「作品展示墙」招牌；品牌仅在发布器标题「画坊作品墙 · 随手贴一张」中出现。
- **搜索行**（固定头）：搜索输入框 + 备份 📦 图标按钮（§4.7）+ 「新手绘画指南」💡 图标按钮（子页面，§2）。
- 发布器位于滚动区顶部，仅下方时间轴滚动。

### 4.2 搜索与筛选（按标签 / 文字）

- 搜索框 placeholder：「搜画作碎碎念或 #标签（如 杯子 / #日常涂鸦）」，支持按**标签**或**正文文字**实时过滤。
- 过滤逻辑：命中记录即时显示，未命中隐藏；**日期分组标题**随组内是否仍有可见记录联动显隐；输入非空时显示清空（✕）按钮。
- 快捷标签筛选条：`#全部 #日常涂鸦 #耐丑打卡 #情绪宣泄 #生活小物`，与搜索可组合。
- 无任何命中 → 显示空状态「没找到相关作品，换个词试试～」。
- 搜索行右侧：📦 备份入口（components §19）、💡 指南入口（components §3.4，与搜索输入同一行）。

### 4.3 发布器（Input Area）

- **折叠/展开**：卡片默认展示「画坊作品墙 · 随手贴一张」，直接呈现完整编辑区。
- **字段**：
  - 多行碎碎念文本域（`--fs-body`，`min-height` 约 2 行，placeholder："写点关于这幅画的碎碎念（选填，长文也可完整生成小红书配文）…"）。**碎碎念选填**。
  - **图片上传（必选）**：`[📷 拍画作 / 选相册 (必选)]`（`accept="image/*"`）；选中后**前端压缩预览**（Web Worker + `createImageBitmap`/`OffscreenCanvas`，限制最长边、纠 EXIF 方向，**存 Blob 不存 Base64**），缩略图带「已压缩」角标与移除 ✕。
    - **✨ 提亮纸面滤镜**：预览区提供一键【提亮纸面（去阴影）】开关（components §16），针对夜晚台灯下拍画纸发灰场景优化明度 / 对比度。
    - **未选图即发布**：给出轻提示 Toast（§components §21）并高亮引导传图。
  - 标签选择：预设 `#日常涂鸦 / #耐丑打卡 / #情绪宣泄 / #生活小物`，可多选（Tag 组件，默认选中 `#日常涂鸦`）。
  - 操作：[盖章上墙 💮]（主按钮）。发布中按钮 loading、禁用重复提交。
- 发布后：写入 IndexedDB（存 Blob），列表顶部插入**新记录**（分组按日期），发布器清空并收起重置。
- 每次重绘列表须对旧图调用 `URL.revokeObjectURL` 释放内存。

### 4.4 时间轴列表与作品卡操作

- 按 `createdAt` 倒序；按日期分组，组头为手写体日期（`--font-hand`）。
- 单条记录卡（components §6 记录卡）：图片（懒加载）→ 碎碎念 → 标签 → 底部操作条。
- 训练归档的记录会带模式标签（看图 → `#耐丑打卡`，一句话 → `#日常涂鸦` 等，见 §5.5）。
- 底部操作条（components §17）：`[生成分享图]` + `[✏️ 编辑]` + `[删除]`。
  - **✏️ 二次编辑**：打开编辑弹层（components §17.1），可改碎碎念、增删标签或添加自定义标签。
  - **🛡️ 防误删二次确认**：`[删除]` 原位变为红色 `确认取下?`（3 秒自动还原），再次点击才删除（components §18）。
  - **🔍 灯箱**：点击画作图片全屏高清放大看笔触（components §20）。

### 4.5 分享图弹层（Share to XHS）

- 点击【生成分享图】→ 打开分享海报弹层（components §15）：**Canvas 2D 原生直绘 900×1200 3:4 海报**（不依赖 html2canvas），仅保留顶部画坊名与时间、超大拍立得画框、底部标签与「今日动笔 · 松鸦画坊留念」印章，画幅 70%+。
- 弹层内容：
  - **样式自定义栏**：填充方式 `[完整留白 / 铺满画框]` + 底纸 3 色 `燕麦白(oat) / 复古牛皮纸(kraft) / 鼠尾草绿(sage)`，切换即重绘预览。
  - 3:4 海报预览图（支持长按保存）。
  - **小红书笔记配文**：自动整合完整碎碎念正文 + 标签 + `#松鸦画坊 #随手画两笔 #日常速写`，提供 `[📋 复制全文]` / `[📋 复制配文]` 一键复制，及 `[⬇️ 保存海报]`。
- 生成中显示骨架 / loading，避免白屏。

### 4.6 松鸦打气站（Cheer Up）

- 作品墙右下角悬浮🐦 `[松鸦打气]` 药丸按钮（components §10）。
- 点击弹出 `modal-cheer`：松鸦店长叼来的反焦虑暖心字条（随机语录），含 `[再抽一张 🎲]` 与 `[被安慰到了 💛]`。

### 4.7 数据备份与恢复（Backup）

- 搜索行 📦 图标打开备份弹层（components §19）：展示存储统计（上墙画作数 / 摘抄数 / 今日训练数）。
- 提供 `[📤 导出全部画坊备份 (.json)]` 与 `[📥 从备份文件恢复数据]`。
- 数据全部本地 IndexedDB，不上传服务器；存储配额写入失败时给出明确提示并引导导出。

### 4.8 状态与交互

| 状态 | 表现 |
| --- | --- |
| 空 | 空状态插画 + "还没有作品，去贴第一张贴纸吧" |
| 有数据 | 时间轴列表 |
| 未传图发布 | 轻提示 Toast + 高亮传图入口 |
| 发布中 | 发布按钮 loading，禁用重复提交 |
| 存储失败 | 提示"存不下了，试试导出备份"，引导导出 |

- 空状态与列表均为离线可用；数据写入失败（配额）时给出明确提示。

## 5. 页面四：耐丑训练室 TrainingView

**定位**：用限时/不限时的"随手画"强制打破完美主义；不评判丑美，画完就赢。

### 5.1 布局

```text
[固定头]  [📷 看图速写 (10m) ｜ ✨ 一句话画图]   [营业牌 ● 营业中 · 0 次]   ← Segmented（components §14）+ 营业牌（§8）
[训练进行时]  模式 A：暖橘渐变倒计时条（鼓励语 + mm:ss + 白色发光进度条）
              模式 B：温和鼓励条（"随手画两笔 · 不限时自由发挥"）
─────────────────────────────
模式 A（看图速写）：
[画板卡]  今日参考：xxx      点击画题可放大
          [大面积画题图]（点击 → 灯箱放大）
          👀 观察提示：先看成圆、方、三角组合，大胆下笔！
  idle： [🎲 换一张内置图] [🖼️ 自选/拍张图]
         [选好画题了 · 开始 10 分钟速写 ⏱️]
  running：[放弃本局] [画完啦！提前交卷盖章 💮]
─────────────────────────────
模式 B（一句话画图）：
[脑洞画题签]  来自：画坊话签罐
          “句子…” —— 松鸦画坊内置句库 / 我的文摘
          💡 不设倒计时，火柴人 / 抽象线条都算满分！
  idle： [🔄 换一句画题（含我的文摘收藏）] [就画这句 · 开始动笔 🎨]
  running：[重选题目] [画完啦！完成盖章 💮]
─────────────────────────────
```

- 顶部无「速写挑战台」招牌；**固定头**含模式切换 + 营业牌，其下为内容滚动区。
- 两种模式**共用一个训练完成弹层**（§5.5）。

### 5.2 模式 A：看图速写（限时）

- **参考图来源（两种）**：
  - **内置**：从**内置本地矢量参考图库**随机取一张（生活小物 / 手作 / 植物），进入页面先随机展示，[🎲 换一张内置图] 再随机。
  - **自选 / 上传**：从相册 / 相机选一张自己的图作为画题；上传后前端压缩预览（与作品墙发布器同源能力）。
- **画板卡**：大面积画题图 + 木夹子装饰（components §6）；选定后**锁定为本题画题**。**点击画题可全屏放大观察**（灯箱 components §20）。
- **待命态（idle）**：只呈现画板卡 + [换一张内置图] / [自选·拍张图] + [选好画题了 · 开始 10 分钟速写]，**不出现倒计时**，也**不展示刻意鼓励语**。
- **计时态（running）视觉**：**顶部一块鲜明的倒计时条**（暖橘→番茄渐变底 + 白色发光进度条 + 大号白色 `mm:ss`），下方为**大面积画题图**供照着画。
- **计时器**：
  - 固定 **10:00** 倒计时，**选好图之后才开始**——idle 阶段可自由换图 / 上传，点 [开始挑战]（= 确认当前画题）后才启动计时。
  - **实现要点**：基于「截止时间戳 − 当前时间」计算剩余，不依赖 `setInterval` 累加（后台节流 / 锁屏会暂停）。
  - 计时期间申请 **Screen Wake Lock** 防熄屏；离开页面 / 结束时释放。

### 5.3 模式 B：一句话画图（不限时）

- **灵感来源**：优先取「文摘」（§3）收藏中的句子；若从文摘 [🎨 画这句] 进入则**预填该句**。也可从内置句库随机取句；提供 [🔄 换一句画题]。
- **不限时**：无倒计时、无进度环，不申请 Wake Lock；允许慢慢画、慢慢改。
- **脑洞画题签**：句子签常驻显示灵感句与来源徽标（`来自：画坊话签罐` / 我的文摘）。
- **规则提示条**：温和鼓励语（如"不设倒计时，哪怕画成火柴人或者抽象线条都算满分！"）。
- 完成后同样进入完成弹层与打卡闭环。

### 5.4 状态机

```text
模式 A（限时）
idle ──[选好画题·开始10分钟]──▶ running ──[倒计时归零 / 提前交卷]──▶ finished ──[贴上作品墙]──▶ 归档并 +1
  ▲                                                                              │
  └────────────────────────[重置为下一轮]◀───────────────────────────────────────┘

模式 B（不限时）
idle ──[就画这句·开始动笔]──▶ drawing ──[画完啦！完成盖章]──▶ finished ──[贴上作品墙]──▶ 归档并 +1
  ▲                                                                              │
  └────────────────────────[重置为下一轮]◀───────────────────────────────────────┘
```

| 模式 | 状态 | 内容 | 主操作 |
| --- | --- | --- | --- |
| A | idle | 画板卡（内置随机 / 自选上传）+ 观察提示（无倒计时、无刻意鼓励语） | [选好画题了 · 开始 10 分钟速写] |
| A | running | 顶部鲜明倒计时条 + 下方大面积画题图，其余弱化 | [放弃本局] / [画完啦！提前交卷盖章] |
| A | finished | 完成弹层：印章动效 + 撒花 + 夸奖文案 | [贴上【作品墙】💮] |
| B | idle | 脑洞画题签、来源徽标、规则提示条 | [就画这句 · 开始动笔] |
| B | drawing | 句子签常驻，无计时 | [画完啦！完成盖章] / [重选题目] |
| B | finished | 完成弹层：印章动效 + 文案 | [贴上【作品墙】💮] |

- 切换模式（components §14）会重置当前会话状态回到 idle。
- 模式 A 的 idle 阶段可自由换图 / 上传，确认选好图后点开始才启动 10:00 倒计时。
- 结束后反馈：印章动效（components §4）；`vibrate` 仅 Android，iOS 用视觉 + WebAudio 合成音兜底。

### 5.5 打卡闭环（训练完成弹层）

- 完成时弹出 `modal-training-done`：
  - **大印章**：三层结构「松鸦画坊 / 今日动笔 / 今日第 n 章」（components §4）。
  - **撒花 Canvas 覆盖层**：达 5 次及以上时每次完成均触发。
  - **夸奖文案**：随次数递进（如"太棒了！你又战胜了白纸！"），达 5 次起显示「🌟 超常营业达成！」徽标 + 金章。
  - **打卡上传区**：`[📸 立即拍照 / 选速写图打卡 (必传)]` + 可选感受输入；主操作 `[贴上【作品墙】💮]`，或 `[仅记次数]` 跳过上传。
- 上传打卡 → 前端压缩 → 自动按模式打标签归档到「作品墙」→ 营业牌进度 +1。
  - 模式 A → 训练类标签（`#耐丑打卡`）
  - 模式 B → 随手画类标签（`#日常涂鸦`）
- 打卡成功可在作品墙看到新记录；训练页回到 idle 供下一轮。

### 5.6 每日进度与肯定（不设上限）

- 营业牌（components §8）：显示"营业中 · n 次"，进度按**日期 Key** 存储，跨天自动重置；两种模式**共用同一进度计数**。
- **第 5 次起（强烈肯定）**：当日累计达 **5 次及以上**时，**每一次**提交都弹出金章 + **撒花动画**，文案如"五连开张 · 状态拉满"。
- **不封顶、不结束**：超过 5 次后每次完成继续触发金章 + 撒花，营业牌文案递进（`营业中 · n 次` → `🌟超常营业 · 5 次` → `🔥超常营业 · n 次` → `👑今日卷王 · n 次`）。

## 6. 页面间关系

```text
作品墙 ──(💡 指南图标)──▶ 反焦虑绘画指南（子页面，返回箭头回作品墙）
绘画指南 ──(底部引导卡)──▶ 耐丑训练室
文摘 ──(【🎨 画这句】预填句子)──▶ 耐丑训练室 · 一句话画图
耐丑训练室 ──(打卡自动归档 #耐丑打卡 / #日常涂鸦)──▶ 作品墙
文摘 ──(作为灵感句库)──▶ 耐丑训练室 · 一句话画图
作品墙 ──(Canvas 3:4 海报 + 配文复制)──▶ 小红书分享
作品墙 ──(🐦 松鸦打气)──▶ 反焦虑暖心字条
```

- 训练页（两种模式）产生的记录统一进入作品墙时间轴，保证"打卡闭环"完整。
- 文摘既独立成页，又作为「一句话画图」的句子来源。
- 反焦虑绘画指南自「作品墙」搜索行的 💡 图标进入，为子页面，返回后回到作品墙。
- 「松鸦打气」仅在作品墙页提供；指南页通过底部引导卡引流到训练室。
