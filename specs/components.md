# 松鸦画坊 · Chill Sketch Hut 组件规范 (Components)

> 所属：松鸦画坊 Chill Sketch Hut　｜　依赖：[design-tokens.md](./design-tokens.md)
> 说明：所有尺寸 / 颜色 / 动效均引用设计变量；文中「→」表示状态流转。
> 版本：对齐 PRD [chill_sketch_hut_v1_4.md](../chill_sketch_hut_v1_4.md)

## 0. 通用交互原则

- **纸张感**：卡片有轻微悬浮与暖色阴影，不使用生硬边框与冷灰。
- **手作感**：允许轻微倾斜（`±1~2deg`）、胶带 / 图钉 / 印章等"痕迹"，避免过度规整。
- **即时反馈**：所有可点击元素按压时 `scale(.97)` + 阴影收紧，时长 `--dur-fast`。
- **触控优先**：可点击区域 ≥ `--touch-min`（44px）。
- **兜底**：无振动 / 无音效能力的设备静默降级，不影响流程。

## 1. App Shell（全局骨架）

```text
┌───────────────────────────────┐
│  Header（标题 / 搜索行，固定）   │  ← 见 §3；不随内容滚动
├───────────────────────────────┤
│                               │
│        内容滚动区（唯一滚动容器）│  ← 底部预留 --nav-h + --safe-b
│                               │
│                         (FAB) │  ← 见 §10
├───────────────────────────────┤
│   文摘 │  作品墙 │ 耐丑训练   │  ← 底部导航（3 Tab），见 §2
└───────────────────────────────┘
```

- 内容区宽度上限 `--content-max`，桌面居中显示。
- **固定头 + 单一滚动区**：页面纵向 flex，`Header`（标题 / 搜索行 / 新增入口 / 返回栏等）固定不动，仅下方列表容器 `overflow-y:auto` 滚动；`Header` 不随页面滚动。
- 滚动容器 `padding-bottom: calc(var(--nav-h) + var(--safe-b) + var(--sp-6))`，避免被导航遮挡。
- 页面高度用 `100dvh`，滚动容器独立，实现原生 App 的沉浸式体验。

## 2. 底部导航 Bottom Navigation

### 2.1 结构

```text
┌───────────┬───────────┬───────────┐
│  [icon]   │  [icon]   │  [icon]   │
│   文摘     │  作品墙    │  耐丑训练  │
└───────────┴───────────┴───────────┘
  ↑ 激活项：木牌高亮
```

- 三个 Tab 平分宽度，每项内容为「SVG 图标(24×24) + 文字(--fs-tiny)」，纵向排列，居中。
- 容器：`position:fixed; bottom:0`，高 `--nav-h`，`padding-bottom: --safe-b`。
- 背景：`--color-paper-dark`，顶部 `1px --border` 分割线；可叠加一条极淡木纹横条暗示"柜台"。
- **绘画指南不是底部 Tab**：作为「作品墙」的子页面打开（见 §3.3），进入子页时底部导航仍高亮「作品墙」。

### 2.2 状态

| 状态 | 表现 |
| --- | --- |
| 默认 | 图标 `--text-muted`，文字 `--text-muted` |
| 激活 | 图标与文字 `--color-sage-deep`；**图标下方或上方出现一小块圆角木牌色块**（`--color-sage-soft` 或 `--color-wood-light`）作为"被选中的招牌" |
| 按压 | `scale(.97)`，`--dur-fast` |
| 过渡 | 激活木牌滑块移动 `--dur` + `--ease-out` |

### 2.3 交互

- 点击 → 切换路由；切换同时触发 `navigator.vibrate(10)`（Android，可选）。
- 可访问性：激活项加 `aria-current="page"`。

### 2.4 文案映射

| Tab | 图标建议 | 文案 |
| --- | --- | --- |
| 文摘 | 书签 / 摘抄本 | 文摘 |
| 作品墙 | 相框 / 本子 | 作品墙 |
| 训练 | 计时器 / 铅笔 | 耐丑训练 |

> 绘画指南不再占用底部 Tab，入口改为「作品墙」搜索行右侧的小图标（见 §3.3）。

## 3. 页面标题与入口 Header

### 3.1 页面招牌（已移除）

- 早期设计每个页面顶部有「木牌招牌」，**现已全部移除**：为保持界面清爽、把垂直空间让给内容，各 Tab 页不再展示招牌 / 标题条。
- 「店铺招牌」作为品牌视觉锤（§2.2）仅保留在品牌层（如开屏 / 图标），不在 Tab 页内重复出现。

### 3.2 小节标题 Section Label

- 形态：小吊牌 / 和纸胶带标签，背景 `--color-wood-light` 或 `--color-yellow`，圆角 `--radius-sm`，文字 `--font-title` / `--fs-h2` / `--color-ink`。
- 前置可加一个小图钉或圆形序号点。

### 3.3 子页面顶栏 Subpage Head（返回箭头）

用于以子页面形式打开的二级页（当前为「新手绘画指南」）。

- **形态**：一行横向布局 —— 左侧圆形返回按钮、中间居中标题、右侧占位（保持标题居中）。
- 返回按钮：直径 36px 圆形，`--surface` 底 + `1.5px --border` 描边 + `--shadow-card`，图标为 `‹`；点击返回上一页（指南 → 返回「作品墙」）。
- 标题：`--font-title` / 约 `--fs-h2`，`--color-ink`，字距略松。
- 顶栏固定在页面头部，不随内容滚动（同 §1 固定头原则）。

### 3.4 新手指南入口 Guide Entry

- **位置**：「作品墙」顶部搜索行，与搜索输入框**同一行、紧贴其右侧**。
- **形态**：一枚小巧圆形图标按钮（直径约 44px，满足 `--touch-min`），暖黄渐变底 `--color-yellow → 浅黄`，图标为 💡（灯泡 / 灵光）。
- 点击 → 打开「新手绘画指南」子页面（§3.3）。
- 语义：`aria-label="新手绘画指南"`，并带 `title` 提示。

**历史（已废弃）**：曾以「作品墙顶部整条黄色卡片按钮」与「底部独立 Tab」两种形态出现，现统一收敛为上述搜索行小图标。

## 4. 印章动效 Stamp Animation

### 4.1 触发场景

| 场景 | 印章文案 | 印章色 |
| --- | --- | --- |
| 作品墙打卡成功 | 已打卡 · 松鸦画坊留念 | `--color-seal` |
| 训练完成 | 今日动笔 · 松鸦画坊留念 | `--color-seal` |
| 每日训练达 5 次及以上（每次提交都触发，含第 5 次） | 五连开张 → 超常营业 → 今日卷王（递增） | `--color-seal-gold` + 星标叠加 + **撒花动画** |

> 训练完成印章内部结构（与原型一致）：上部小字「松鸦画坊」、中部大字「今日动笔」、下部「今日第 n 章」。朱红双圈 + 轻微旋转（约 `-10deg`）+ `stampIn` 落章回弹。

### 4.2 视觉构成

- **印章本体**：SVG 圆形，双线描边（外粗内细），中间横排文字；整体带轻微"缺墨 / 毛边"质感（可用 `mask` 噪点或轻微旋转）。
- **遮罩**：全屏 `rgba(74,66,56,.35)` 淡入，中央留白给印章。
- **粒子**：落定瞬间迸发 6~8 个墨点，向外扩散后消失。

### 4.3 动效流程（逐阶段）

```text
阶段0 准备        阶段1 落章(回弹)   阶段2 触印    阶段3 墨迹回稳   阶段4 结果   阶段5 退场
遮罩淡入    →    印章放大落下     →   闪/粒子+抖动 →   轻微扩散回稳   →  文案浮现  →  淡出/留印
0–80ms         80–360ms           360–460ms      460–600ms       600–1200ms   1200–1500ms
```

| 阶段 | 时间段 | 属性变化 | 缓动 |
| --- | --- | --- | --- |
| 0 准备 | 0–80ms | 遮罩 `opacity 0→1` | `--ease-out` |
| 1 落章 | 80–360ms | 印章 `scale 3→1`、`translateY -40px→0`、`rotate -12deg→-6deg`、`opacity 0→1` | `--ease-bounce` |
| 2 触印 | 360–460ms | 白闪/墨点粒子迸发；画面 `shake ±2px`（100ms）；音效"咚"；`vibrate(30)`（Android） | 线性 |
| 3 墨迹回稳 | 460–600ms | 印章 `scale 1.02→1`，描边轻微回弹 | `--ease-out` |
| 4 结果展示 | 600–1200ms | 章下方文案上浮淡入 `translateY 8px→0` | `--ease-out` |
| 5 退场 | 1200–1500ms | 整体（遮罩+章）`opacity→0`、`scale→.96`；如需长期标记，印章缩小归位到卡片角落 | `--ease-out` |

### 4.4 每日进度的肯定与超额赞扬（不封顶）

- **第 5 次起（强烈肯定）**：当日训练达 **5 次及以上**时，**每一次提交**都弹出金章 + **撒花动画**（20~30 个彩色纸屑，`--color-yellow / --color-pink / --color-sage` 混色，**从底部向上弹出后再自由落下**，先上冲后飘落），文案为专属肯定句，如"五连开张 · 状态拉满"。
- **不封顶、不结束**：超过 5 次后每次完成继续触发上述奖励，并在印章角上叠加**星标 / 小旗**（第 6 次 1 颗，第 7 次 2 颗……），文案按次数递增：
  | 次数 | 文案示例 |
  | --- | --- |
  | 5 | 五连开张 · 状态拉满 |
  | 6 | 超常营业 · 今日 6 张 |
  | 7 | 超常营业 · 今日 7 张 |
  | ≥8 | 今日卷王 · 已画 n 张，收下膝盖 |
- 递增文案由 `data/quotes.js` 提供（含温度、不施压的鼓励语），避免机械重复。

### 4.5 降级与无障碍

- `prefers-reduced-motion: reduce`：跳过阶段 1~2 的位移/抖动，仅保留「遮罩淡入 → 印章直接出现 → 文案」的淡入淡出。
- 无振动 / 音效能力时静默兜底，流程照常。
- 印章结果需保留足够时长（≥ 1200ms）供用户看清，不用动画速度替代信息传达。

### 4.6 实现提示

- 印章用 **SVG**（便于描边与文字排版）；粒子可用少量 `div` 或一次性 `canvas`。
- 时间线建议用 `Web Animations API` 或 CSS `@keyframes` + 单个 `setTimeout` 串阶段，避免多层嵌套定时器。
- 动画执行期间锁定背景滚动。

## 7. 标签 Tag

- 药丸形（`--radius-pill`），字号 `--fs-small`，前缀 `#`。
- 默认：背景 `--color-paper-alt`，文字 `--text-muted`，`1px --border`。
- 选中：背景 `--color-sage-soft`，文字 `--color-sage-deep`，边框 `--brand`。

## 8. 营业牌 Progress Plate（每日进度）

- 位置：训练页顶部（固定头部区，位于模式切换下方），不随内容滚动。
- 形态：一块小木牌（深棕底 + 木色描边 + 暖橘呼吸灯），左侧状态文字（**营业中 · 2 次**），右侧 5 个小圆点 / 小印章（前 5 次映射到点位）。
- 状态文案（与原型一致，由 `data/quotes.js` 分级提供）：
  - `0` 次：营业中 · 0 次
  - `1~4` 次：营业中 · n 次
  - `5` 次：🌟 超常营业 · 5 次（强烈肯定）
  - `6~7` 次：🔥 超常营业 · n 次
  - `≥8` 次：👑 今日卷王 · n 次
- 状态：
  - 未满 5 次：已完成的点位填充 `--color-seal`，未完成留空心。
  - 第 5 次（强烈肯定）：整块牌切换为 `--color-seal-gold` 描边，5 点全实心。
  - 超过 5 次（超额赞扬，不封顶）：点位前置显示星标计数（第 6 次 1 颗星、第 7 次 2 颗……），文字与星标一同升级为赞扬语气。

│ 营业中 · 2 次       ● ● ○ ○ ○  │
└──────────────────────────────┘

超过 5 次：
┌──────────────────────────────┐
│ 🔥 超常营业 · 7 次  ★★ ●●●●●  │

## 10. 松鸦打气站 Cheer Up（悬浮入口）

- 位置：右下角，距底部导航上方 `--sp-4`，右侧 `--sp-4`；悬浮于作品墙上方。
- 形态（与原型一致）：**药丸形按钮**，`--surface` 底 + `2px --accent` 描边 + `--shadow-float`，内含 🐦 图标 + 「松鸦打气」文字（`--font-title` / `--fs-small`）。
- 按压 `scale(.94)`；点击弹出「松鸦店长叼来的纸条」语录气泡：暖黄圆形鸟头图标 + 「—— 松鸦店长叼来一张纸条 ——」引导语 + 随机语录 + `[再抽一张 🎲]` / `[被安慰到了 💛]` 按钮。

- 统一线条圆润、带手绘感的轻量 **SVG**，`stroke-width` 约 1.8–2，避免尖锐直角。

## 13. 文摘卡片 Excerpt Card

用于「文摘」列表中的单条句子，也复用于文摘页与训练页的句子来源。

- **形态**：句子卡（§6），背景 `--color-paper-alt`，圆角 `--radius-lg`，内边距 `--sp-4`，阴影 `--shadow-card`；左上角一枚淡色"引号"装饰。
- **内容**：
  - 句子正文：`--font-hand`（手写体）或 `--fs-h2`，`--color-ink`，允许多行。
  - 出处 / 作者：`--fs-small` / `--text-muted`，可选，前置破折号 `——`。
  - 标签：Tag 组件（§7），可选。
- **底部操作条**：`[收藏 ★]`（星标，选中转 `--color-seal-gold`）+ `[🎨 画这句]`（强调按钮 Accent，跳转训练"一句话画图"并预填该句）+ `[编辑]` / `[删除]`（文字按钮，删除采用「原位二次确认」，见 §18）。
- **收藏态**：星标点亮，卡片右上角展示金色小星；可据此筛选。
- **降级**：句子超长时省略号截断，点击卡片展开全文。

## 14. 训练模式切换 Segmented（看图速写 / 一句话画图）

- 位置：训练页固定头部区最上方，其下为营业牌（§8）；不随内容滚动。
- **形态**：木牌风格的**分段控件**，两块圆角"小木片"并排，选中项背景 `--color-sage-soft`、文字 `--color-sage-deep`，未选中透明底、文字 `--text-muted`；滑块切换 `--dur` + `--ease-out`（同底部导航木牌逻辑）。
- **文案**：

  | 模式 | 标签 | 说明 |
  | --- | --- | --- |
  | A | 看图速写 | 随机参考图 + 10:00 限时 |
  | B | 一句话画图 | 一句话灵感 + 不限时 |

- 切换时重置当前会话状态（回到 idle），两种模式共用营业牌进度与印章肯定机制。

## 15. 分享海报弹层 Poster Overlay（v1.4 新增）

**用途**：把上墙画作生成为小红书 3:4「纯享海报」并一键复制配文。

- **形态**：遮罩（`rgba(74,66,56,.70)`）+ 居中卡片（`--radius-xl` + `2px --wood` 描边 + `--shadow-float`）；卡片内自上而下：标题栏（📕 小红书 3:4 纯享画作卡 + `大图版` 角标 + 关闭 ✕）→ **样式自定义栏** → 海报预览（`aspect-ratio: 3/4`）→ 配文预览 + 复制区 → 底部操作条。
- **海报绘制**：Canvas 2D 原生绘制 **900×1200**，不用 `html2canvas`。70%+ 超大画幅，仅保留顶部画坊名与时间、超大拍立得画框、底部标签与「今日动笔 · 松鸦画坊留念」印章，不堆长文字。
- **样式自定义栏**：
  - 填充方式分段控件：`[完整留白]`（contain，默认）/ `[铺满画框]`（cover）。
  - 底纸配色 3 选 1 圆点：`--poster-oat`（燕麦白，默认）/ `--poster-kraft`（复古牛皮纸）/ `--poster-sage`（鼠尾草绿）；选中圆点加 `ring` 描边。
  - 切换后即时重绘，无 loading 闪烁。
- **配文一键复制**：只读文本域展示「碎碎念正文 + 标签 + `#松鸦画坊 #随手画两笔 #日常速写`」整合文案；`[📋 复制全文]` / `[📋 复制配文]` 触发复制 + Toast 反馈。
- **底部操作条**：`[📋 复制配文]`（主按钮 sage）+ `[⬇️ 保存海报]`（强调按钮 tomato，下载 PNG / 引导长按保存）。

## 16. 提亮纸面滤镜 Brighten Toggle（v1.4 新增）

**用途**：针对夜晚台灯下拍画纸发灰，一键优化对比度与明度。

- **位置**：作品墙发布器「图片上传预览区」内，紧邻缩略图。
- **形态**：药丸小按钮 `[✨ 提亮纸面 (去阴影)]` / `[✨ 已提亮纸面 (点击还原)]` / `[⏳ 正在提亮纸面...]`（处理中）。
- **行为**：切换时对**已压缩的 Blob** 做亮度 / 对比度增强（Canvas `filter: brightness() contrast()` 重绘后回写 WebP/JPEG），保留原图 Blob 以便还原；处理中禁用按钮 + 文案提示，完成 Toast「已提亮画纸背景，线条更清晰啦！」。
- **降级**：Canvas `filter` 不可用时隐藏该开关，静默不影响发布。

### 17.1 二次编辑弹层 Edit Record Modal

- **形态**：遮罩 + 居中卡片（`--radius-xl`），标题「✏️ 编辑画作碎碎念与标签」+ 关闭 ✕。
- **内容**：碎碎念多行文本域（可改字）+ 标签区（预设 `#日常涂鸦 / #耐丑打卡 / #一句话画图 / #情绪宣泄 / #生活小物`，可点选 / 取消，至少保留 1 个）+ 自定义标签输入 `[＋添加]`。
- **操作**：`[保存修改 💮]`（主按钮 sage）→ 更新 IndexedDB 对应记录 → 重绘时间轴 + Toast。
- 仅编辑文字与标签，**不改图片**。

## 18. 防误删原位二次确认 Inline Delete Confirm（v1.4 新增）

- **触发**：点击卡片/句子卡上的 `[删除]` 文字按钮。
- **表现**：按钮**原位**变为红色 `确认取下?`（背景 `--color-tomato` + 白字 + 略加内边距），进入 3 秒确认态。
- **超时**：3 秒内未二次点击则自动还原为 `[删除]` 与原样式。
- **确认**：3 秒内再次点击 → 执行删除（IndexedDB）+ 重绘 + Toast「已从作品墙取下」。
- 目的：兼顾移动端滑动误触保护与「不弹窗打断」的轻量体验。

## 19. 数据备份与恢复弹层 Backup Modal（v1.4 新增）

**用途**：防浏览器清理导致作品与文摘丢失；全程本地，不上传服务器。

- **入口**：作品墙固定头搜索行右侧的 `[📦]` 备份按钮。
- **形态**：遮罩 + 居中卡片，标题「📦 画坊数据备份与恢复」+ 关闭 ✕ + 隐私说明文案。
- **统计区**：`🖼️ 上墙画作 n 幅` / `🔖 摘抄句子 n 条` / `💮 今日训练 n 次`（实时统计）。
- **操作**：`[📤 导出全部画坊备份 (.json)]`（主按钮 sage，图片以 Blob/内联打包）+ `[📥 从备份文件恢复数据]`（次样式 label + `accept="application/json"` 导入）。
- 导入需二次确认，避免覆盖本地数据。

## 20. 灯箱 Lightbox（v1.4 新增）

- **入口**：点击上墙画作图片 / 参考图 / 训练画题（`cursor: zoom-in`）。
- **形态**：全屏 `rgba(0,0,0,.85)` 遮罩 + 居中大图（`max-h:78dvh` + `--radius-lg` + 纸底内边距 + 木色描边）；下方一行说明文案；底部提示「轻触任意位置关闭」。

## 21. 轻提示 Toast

- **形态**：顶部居中药丸（`--color-ink` 底 + `--color-paper` 字 + `--wood` 描边 + `--shadow-float`），前置图标 + 文案。
- **动效**：入场 `opacity 0→1` + `translateY(-8px→0)`（`--dur` / `--ease-out`），默认 2.4s 后自动淡出。
- **用途**：发布成功 / 已提亮 / 已取下 / 复制成功 / 已打卡等轻量反馈。图标随语义变化（💮 / ✨ / 🗑️ / 📋）。
