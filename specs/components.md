# 零压画铺 · 组件规范 (Components)

> 所属：零压画铺 Chill Sketch Hub　｜　依赖：[design-tokens.md](./design-tokens.md)
> 说明：所有尺寸 / 颜色 / 动效均引用设计变量；文中「→」表示状态流转。

## 0. 通用交互原则

- **纸张感**：卡片有轻微悬浮与暖色阴影，不使用生硬边框与冷灰。
- **手作感**：允许轻微倾斜（`±1~2deg`）、胶带 / 图钉 / 印章等"痕迹"，避免过度规整。
- **即时反馈**：所有可点击元素按压时 `scale(.97)` + 阴影收紧，时长 `--dur-fast`。
- **触控优先**：可点击区域 ≥ `--touch-min`（44px）。
- **兜底**：无振动 / 无音效能力的设备静默降级，不影响流程。

## 1. App Shell（全局骨架）

```text
┌───────────────────────────────┐
│  Header（标题 / 搜索行，固定）   │  ← 见 §3；不随内容滚动
├───────────────────────────────┤
│                               │
│        内容滚动区（唯一滚动容器）│  ← 底部预留 --nav-h + --safe-b
│                               │
│                         (FAB) │  ← 见 §10
├───────────────────────────────┤
│   文摘 │  我的手账 │  耐丑训练   │  ← 底部导航（3 Tab），见 §2
└───────────────────────────────┘
```

- 内容区宽度上限 `--content-max`，桌面居中显示。
- **固定头 + 单一滚动区**：页面纵向 flex，`Header`（标题 / 搜索行 / 新增入口 / 返回栏等）固定不动，仅下方列表容器 `overflow-y:auto` 滚动；`Header` 不随页面滚动。
- 滚动容器 `padding-bottom: calc(var(--nav-h) + var(--safe-b) + var(--sp-6))`，避免被导航遮挡。
- 页面高度用 `100dvh`，滚动容器独立，实现原生 App 的沉浸式体验。

## 2. 底部导航 Bottom Navigation

### 2.1 结构

```text
┌───────────┬───────────┬───────────┐
│  [icon]   │  [icon]   │  [icon]   │
│   文摘     │  我的手账  │  耐丑训练  │
└───────────┴───────────┴───────────┘
  ↑ 激活项：木牌高亮
```

- 三个 Tab 平分宽度，每项内容为「SVG 图标(24×24) + 文字(--fs-tiny)」，纵向排列，居中。
- 容器：`position:fixed; bottom:0`，高 `--nav-h`，`padding-bottom: --safe-b`。
- 背景：`--color-paper`，顶部 `1px --border` 分割线；可叠加一条极淡木纹横条暗示"柜台"。
- **绘画指南不是底部 Tab**：作为「我的手账」的子页面打开（见 §3.3），进入子页时底部导航仍高亮「我的手账」。

### 2.2 状态

| 状态 | 表现 |
| --- | --- |
| 默认 | 图标 `--text-muted`，文字 `--text-muted` |
| 激活 | 图标与文字 `--color-sage-deep`；**图标下方或上方出现一小块圆角木牌色块**（`--color-sage-soft` 或 `--color-wood-light`）作为"被选中的招牌" |
| 按压 | `scale(.97)`，`--dur-fast` |
| 过渡 | 激活木牌滑块移动 `--dur` + `--ease-out` |

### 2.3 交互

- 点击 → 切换路由；切换同时触发 `navigator.vibrate(10)`（Android，可选）。
- 可访问性：激活项加 `aria-current="page"`。

### 2.4 文案映射

| Tab | 图标建议 | 文案 |
| --- | --- | --- |
| 文摘 | 书签 / 摘抄本 | 文摘 |
| 手账 | 相框 / 本子 | 我的手账 |
| 训练 | 计时器 / 铅笔 | 耐丑训练 |

> 绘画指南不再占用底部 Tab，入口改为「我的手账」搜索行右侧的小图标（见 §3.3）。

## 3. 页面标题与入口 Header

### 3.1 页面招牌（已移除）

- 早期设计每个页面顶部有「木牌招牌」，**现已全部移除**：为保持界面清爽、把垂直空间让给内容，各 Tab 页不再展示招牌 / 标题条。
- 「店铺招牌」作为品牌视觉锤（§2.2）仅保留在品牌层（如开屏 / 图标），不在 Tab 页内重复出现。

### 3.2 小节标题 Section Label

- 形态：小吊牌 / 和纸胶带标签，背景 `--color-wood-light` 或 `--color-yellow`，圆角 `--radius-sm`，文字 `--font-title` / `--fs-h2` / `--color-ink`。
- 前置可加一个小图钉或圆形序号点。

### 3.3 子页面顶栏 Subpage Head（返回箭头）

用于以子页面形式打开的二级页（当前为「新手绘画指南」）。

- **形态**：一行横向布局 —— 左侧圆形返回按钮、中间居中标题、右侧占位（保持标题居中）。
- 返回按钮：直径 36px 圆形，`--surface` 底 + `1.5px --border` 描边 + `--shadow-card`，图标为 `‹`；点击返回上一页（指南 → 返回「我的手账」）。
- 标题：`--font-title` / 约 `--fs-h2`，`--color-ink`，字距略松。
- 顶栏固定在页面头部，不随内容滚动（同 §1 固定头原则）。

### 3.4 新手指南入口 Guide Entry

- **位置**：「我的手账」顶部搜索行，与搜索输入框**同一行、紧贴其右侧**。
- **形态**：一枚小巧圆形图标按钮（直径约 44px，满足 `--touch-min`），暖黄渐变底 `--color-yellow → 浅黄`，图标为 💡（灯泡 / 灵光）。
- 点击 → 打开「新手绘画指南」子页面（§3.3）。
- 语义：`aria-label="新手绘画指南"`，并带 `title` 提示。

**历史（已废弃）**：曾以「手账顶部整条黄色卡片按钮」与「底部独立 Tab」两种形态出现，现统一收敛为上述搜索行小图标。

## 4. 印章动效 Stamp Animation

### 4.1 触发场景

| 场景 | 印章文案 | 印章色 |
| --- | --- | --- |
| 手账打卡成功 | 已打卡 | `--color-seal` |
| 训练完成 | 画完就赢 | `--color-seal` |
| 每日训练达 5 次及以上（每次提交都触发，含第 5 次） | 五连开张 → 超常营业 → 今日卷王（递增） | `--color-seal-gold` + 星标叠加 + **撒花动画** |

### 4.2 视觉构成

- **印章本体**：SVG 圆形，双线描边（外粗内细），中间横排文字；整体带轻微"缺墨 / 毛边"质感（可用 `mask` 噪点或轻微旋转）。
- **遮罩**：全屏 `rgba(74,66,56,.35)` 淡入，中央留白给印章。
- **粒子**：落定瞬间迸发 6~8 个墨点，向外扩散后消失。

### 4.3 动效流程（逐阶段）

```text
阶段0 准备        阶段1 落章(回弹)   阶段2 触印    阶段3 墨迹回稳   阶段4 结果   阶段5 退场
遮罩淡入    →    印章放大落下     →   闪/粒子+抖动 →   轻微扩散回稳   →  文案浮现  →  淡出/留印
0–80ms         80–360ms           360–460ms      460–600ms       600–1200ms   1200–1500ms
```

| 阶段 | 时间段 | 属性变化 | 缓动 |
| --- | --- | --- | --- |
| 0 准备 | 0–80ms | 遮罩 `opacity 0→1` | `--ease-out` |
| 1 落章 | 80–360ms | 印章 `scale 3→1`、`translateY -40px→0`、`rotate -12deg→-6deg`、`opacity 0→1` | `--ease-bounce` |
| 2 触印 | 360–460ms | 白闪/墨点粒子迸发；画面 `shake ±2px`（100ms）；音效"咚"；`vibrate(30)`（Android） | 线性 |
| 3 墨迹回稳 | 460–600ms | 印章 `scale 1.02→1`，描边轻微回弹 | `--ease-out` |
| 4 结果展示 | 600–1200ms | 章下方文案上浮淡入 `translateY 8px→0` | `--ease-out` |
| 5 退场 | 1200–1500ms | 整体（遮罩+章）`opacity→0`、`scale→.96`；如需长期标记，印章缩小归位到卡片角落 | `--ease-out` |

### 4.4 每日进度的肯定与超额赞扬（不封顶）

- **第 5 次起（强烈肯定）**：当日训练达 **5 次及以上**时，**每一次提交**都弹出金章 + **撒花动画**（20~30 个彩色纸屑，`--color-yellow / --color-pink / --color-sage` 混色，**从底部向上弹出后再自由落下**，先上冲后飘落），文案为专属肯定句，如"五连开张 · 状态拉满"。
- **不封顶、不结束**：超过 5 次后每次完成继续触发上述奖励，并在印章角上叠加**星标 / 小旗**（第 6 次 1 颗，第 7 次 2 颗……），文案按次数递增：
  | 次数 | 文案示例 |
  | --- | --- |
  | 5 | 五连开张 · 状态拉满 |
  | 6 | 超常营业 · 今日 6 张 |
  | 7 | 超常营业 · 今日 7 张 |
  | ≥8 | 今日卷王 · 已画 n 张，收下膝盖 |
- 递增文案由 `data/quotes.js` 提供（含温度、不施压的鼓励语），避免机械重复。

### 4.5 降级与无障碍

- `prefers-reduced-motion: reduce`：跳过阶段 1~2 的位移/抖动，仅保留「遮罩淡入 → 印章直接出现 → 文案」的淡入淡出。
- 无振动 / 音效能力时静默兜底，流程照常。
- 印章结果需保留足够时长（≥ 1200ms）供用户看清，不用动画速度替代信息传达。

### 4.6 实现提示

- 印章用 **SVG**（便于描边与文字排版）；粒子可用少量 `div` 或一次性 `canvas`。
- 时间线建议用 `Web Animations API` 或 CSS `@keyframes` + 单个 `setTimeout` 串阶段，避免多层嵌套定时器。
- 动画执行期间锁定背景滚动。

## 5. 按钮 Button

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| 主按钮 Primary | 背景 `--brand`(sage)，文字米白，圆角 `--radius-pill`，高 44–48px | 发布、保存、开始 |
| 强调按钮 Accent | 背景 `--accent`(orange)，文字米白 | "开始挑战"等关键行动 / "营业"语义 |
| 次按钮 Secondary | 透明底 + `1.5px --brand` 描边，文字 `--brand` | 次级操作、取消 |
| 文字按钮 Text | 无底，文字 `--brand` 或 `--text-muted` | 轻量操作 |
| 禁用 Disabled | 背景 `--border`，文字 `--text-muted`，不响应 | 条件未满足 |

- 内边距 `--sp-3 --sp-6`，字号 `--fs-body`；宽度可按需 `block`（整行）或自适应。
- 按压：`scale(.97)` + 阴影收紧，`--dur-fast`。

## 6. 卡片 Card（便签 / 吊牌 / 牛皮纸）

| 变体 | 样式 | 用途 |
| --- | --- | --- |
| 记录卡 | 背景 `--surface`，圆角 `--radius-lg`，阴影 `--shadow-card`，内边距 `--sp-4` | 手账时间轴记录 |
| 便签卡 | 背景 `--color-yellow`，轻微倾斜 `-1deg`，可加"胶带"顶饰 | 指南心法 |
| 参考图卡 | 大图 + 图钉/胶带装饰，圆角 `--radius-lg` | 训练参考图 |
| 句子卡 | 背景 `--color-paper-alt`，左上角"引号"装饰，圆角 `--radius-lg` | 文摘 / 一句话画图 |
| 牛皮纸标签 | 背景 `--color-wood-light`，圆角 `--radius-sm` | 日期 / 分类标签 |

- 可选装饰：顶部居中的一小段"和纸胶带"（`--color-wood-light` / `--color-pink`，半透明，倾斜）。
- 图片统一 `object-fit: cover` + 圆角；列表图片懒加载。

## 7. 标签 Tag

- 药丸形（`--radius-pill`），字号 `--fs-small`，前缀 `#`。
- 默认：背景 `--color-paper-alt`，文字 `--text-muted`，`1px --border`。
- 选中：背景 `--color-sage-soft`，文字 `--color-sage-deep`，边框 `--brand`。
- 可选主题色变体：黄 `--color-yellow` / 粉 `--color-pink`（用于特定标签）。

## 8. 营业牌 Progress Plate（每日进度）

- 位置：训练页顶部（固定头部区，位于模式切换下方），不随内容滚动。
- 形态：一块小木牌，左侧状态文字（**今日营业 2 张**），右侧 5 个小圆点 / 小印章（前 5 次映射到点位）。
- 状态：
  - 未满 5 次：已完成的点位填充 `--color-seal`，未完成留空心。
  - 第 5 次（强烈肯定）：整块牌切换为 `--color-seal-gold` 描边，5 点全实心，文字改为"五连开张"。
  - 超过 5 次（超额赞扬，不封顶）：点位前置显示星标计数（第 6 次 1 颗星、第 7 次 2 颗……），文字与星标一同升级为赞扬语气。

```text
未满 5 次：
┌──────────────────────────────┐
│ 今日营业  2 张      ● ● ○ ○ ○  │
└──────────────────────────────┘

超过 5 次：
┌──────────────────────────────┐
│ 超常营业  7 张    ★★ ●●●●●   │
└──────────────────────────────┘
```

## 9. 全屏提示 / 弹层 Overlay

| 类型 | 表现 | 用途 |
| --- | --- | --- |
| 全屏结果层 | 满屏遮罩 + 居中方框（章 + 文案 + 按钮） | 训练完成 |
| 海报弹层 | 居中 3:4 卡片 + 底部操作条 | 分享图预览 |
| 语录气泡 | 从 FAB 弹出的圆角气泡，带尾巴 | 求打气 |

- 遮罩 `rgba(74,66,56,.35)`，点击遮罩可关闭（结果层除外）。
- 弹层入场：`opacity 0→1` + `scale .96→1`，`--dur-slow` + `--ease-out`。

## 10. 悬浮按钮 FAB（求打气）

- 位置：右下角，距底部导航上方 `--sp-4`，右侧 `--sp-4`。
- 形态：圆形（直径 52px），背景 `--accent`(orange)，白色图标（喇叭 / 对话框），阴影 `--shadow-float`。
- 按压 `scale(.94)`；点击弹出语录气泡。

## 11. 空状态 Empty State

- 组成：手绘感插画（铺子 / 空画框）+ 一句铺子语气文案 + 可选行动按钮。
- 文案示例：
  - 手账空："还没有作品，去贴第一张贴纸吧 🌱"
  - 训练空："今天还没开张，来画一张？"

## 12. 图标 Icon

- 统一线条圆润、带手绘感的轻量 **SVG**，`stroke-width` 约 1.8–2，避免尖锐直角。
- 默认尺寸 24×24，随场景缩放；颜色随文字色（`currentColor`）。

## 13. 文摘卡片 Excerpt Card

用于「文摘」列表中的单条句子，也复用于文摘页与训练页的句子来源。

- **形态**：句子卡（§6），背景 `--color-paper-alt`，圆角 `--radius-lg`，内边距 `--sp-4`，阴影 `--shadow-card`；左上角一枚淡色"引号"装饰。
- **内容**：
  - 句子正文：`--font-hand`（手写体）或 `--fs-h2`，`--color-ink`，允许多行。
  - 出处 / 作者：`--fs-small` / `--text-muted`，可选，前置破折号 `——`。
  - 标签：Tag 组件（§7），可选。
- **底部操作条**：`[收藏 ★]`（星标，选中转 `--color-seal-gold`）+ `[画这句]`（强调按钮 Accent，跳转训练"一句话画图"并预填该句）+ `[编辑]` / `[删除]`（文字按钮，删除二次确认）。
- **收藏态**：星标点亮，卡片右上角展示金色小星；可据此筛选。
- **降级**：句子超长时省略号截断，点击卡片展开全文。

## 14. 训练模式切换 Segmented（看图速写 / 一句话画图）

- 位置：训练页固定头部区最上方，其下为营业牌（§8）；不随内容滚动。
- **形态**：木牌风格的**分段控件**，两块圆角"小木片"并排，选中项背景 `--color-sage-soft`、文字 `--color-sage-deep`，未选中透明底、文字 `--text-muted`；滑块切换 `--dur` + `--ease-out`（同底部导航木牌逻辑）。
- **文案**：

  | 模式 | 标签 | 说明 |
  | --- | --- | --- |
  | A | 看图速写 | 随机参考图 + 10:00 限时 |
  | B | 一句话画图 | 一句话灵感 + 不限时 |

- 切换时重置当前会话状态（回到 idle），两种模式共用营业牌进度与印章肯定机制。
